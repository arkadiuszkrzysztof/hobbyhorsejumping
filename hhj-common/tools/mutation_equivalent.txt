# Mutants that survive `make mutation` because the change cannot alter behaviour.
#
# One per line:   file @@ original line @@ mutated line @@ why it cannot matter
#
# `make mutation` fails for a surviving mutant that is not listed here, and for
# an entry here that no longer matches a surviving mutant. Before adding a
# line, try to write a test that fails for the mutant, or to remove the code
# that makes it redundant - most survivors were dealt with that way.
#
# The recurring reasons:
#   (init)     an initial value that is always overwritten before it is read
#   (identity) a comparison that only changes which of two branches handles a
#              value for which both branches give the same result
#   (unique)   a tie that cannot occur, or where either choice is the same
#   (masked)   an error path that says "ok" without consuming input, so the
#              caller fails on the very next character anyway
